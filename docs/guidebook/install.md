# 安装 OpenAI 上游图片优化与 Zstd 压缩

## 升级

1. 在 Sub2API 后台的插件管理上传 `openai-upstream-zstd-1.5.0-linux-amd64.s2plugin`。插件 ID 为 `cn.vipox.openai-upstream-zstd`，发行方为 `vipox-zstd-20261104`。
2. 读取当前配置。已保存的图片开关、Zstd 设置、代理、请求体上限、画质和超时沿用旧值。v1.2.x 的长边和双门槛设置迁移为 1080p 与 32 KiB，旧默认 Q92 迁移为 Q78，较新版本显式保存的画质沿用。
3. 若旧配置保留 64 MiB 换图上限，把「最大换图请求体」设为 0 即可处理更大的请求。开启图片优化并保存，从同一 HTTP 对话发送两轮带图消息，在最近请求里查看上传体积、缓存命中和跳过原因。

## 首次安装

从构建产物 `trusted-publisher.yaml` 取出对应公钥，合并到宿主 `config.yaml` 的 `plugins.trusted_publishers`。宿主读取配置后即可上传并启用 Linux amd64 签名包。0.2.23 处于清单允许范围，启用时宿主可能要求接受未实测的宿主版本。

## 日常配置

- 普通图从 1080p Q78 起步，小字截图可提高尺寸或画质。工具图默认 1440p。如果任务依赖截图的像素坐标，可将工具图设为原尺寸，或在请求里指定 `detail: original`。
- 「最大换图请求体」和「最大压缩请求体」各自按原始请求体计算，填 0 表示不限。图片转换默认有 30 秒预算，编码并发填 0 时按可用 CPU 自动选择，最多 4 个。
- 透明 PNG 转 JPEG 时默认以白底合成，使用深色界面时可选黑底。单图 JPEG 上限 32 MiB、4800 万像素，PNG 上限 24 MiB、2400 万像素，两者单边上限 12000 px。
- Zstd 支持等级 1–9。当前 Go 编码器按 1–2、3–5、6–9 分别映射为快速、标准、高压缩。窗口可选 1、2、4、8、16 或 32 MiB。大请求使用临时目录中的匿名文件。
- 「最近请求」记录上传体积和处理阶段耗时。415 回退行显示两次合计字节。若请求在配置的换图体积上限处被跳过，面板显示该原因，图片数量需等实际扫描才可统计。

参见[本地验证和实测范围](../validation.md)。
