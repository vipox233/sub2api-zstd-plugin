# OpenAI 上游图片优化与 Zstd 压缩

Sub2API 的 OpenAI OAuth HTTP 出站插件。它优化 Codex Responses 中的内联图片，再用 Zstd 压缩请求体。发行包使用现有插件 ID 和签名发行方，运行时为 Linux amd64 静态二进制。

## 安装与升级

1. 在 Sub2API 插件管理上传签名的 `openai-upstream-zstd-1.5.0-linux-amd64.s2plugin`。首次安装时按[安装说明](docs/guidebook/install.md)登记公钥。
2. 读取已保存配置。新装时图片优化默认关闭。升级保留已保存的图片开关、大小上限和 JPEG 画质等设置。
3. 若配置里仍是 64 MiB 的换图上限，填 0 即可对更大的请求换图。开启图片优化后，发送带截图的 HTTP 对话，在面板「最近请求」里核对原始、换图后和最终上传体积。

## 图片设置

| 设置 | 默认值 |
|---|---|
| 普通图 | 1080p，等比缩入 1920 × 1080，竖图对调宽高 |
| 工具图 | 1440p，可改成 1080p、原尺寸或跟随普通图 |
| JPEG 画质 | 78，可设置 1–100 |
| 透明 PNG 底色 | 白色，可改成黑色 |
| 替换门槛 | JPEG 相对原图至少节省 32 KiB，填 0 时只要求更小 |

长短边比达到 3:1 的图片按短边上限等比缩小。显式 `detail: original` 使用原始像素尺寸并尝试重编码。静态 PNG 支持透明、16 位和 eXIf；带 MPF 或尾部数据的 JPEG 使用主图。动画 PNG、坏图、超限图和收益不足的图片使用原图。

同一原图在相同配置和插件版本下生成相同的 JPEG。缓存按图片内容和转换参数索引，历史、续轮和工具图共用。升级改变图片表示时，上游可能重新计算已有前缀。

## 上传与统计

默认 Zstd level 5、8 MiB 匹配窗口、512 MiB 请求体上限。换图和 Zstd 的请求体上限分别设置。较大的请求在读体、换图和压缩阶段排队，上传前归还准备名额。每个缓冲的前 8 MiB 可留在内存，更大的缓冲使用匿名临时文件。

HTTP 415 用同一份换图后 JSON 明文重试一次。面板按传输读取的请求体字节计量，并列出跳过原因、换图耗时及最近 30 条请求。其中两次上传计入对应的一条请求。
